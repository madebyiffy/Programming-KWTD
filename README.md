# Programming KWTD

`KWTD = Know What To Do` 

This repo was born from the confusion of understanding pointers and how they work, perhaps my efforts would save a generation of programmers from melting their brains.

It also serves as a personal knowledge dump, so theres a low chance of collaboration here, but making it private is also stupid becuase anyone could benefit here.




## How To Navigate

Click on the folder for the topic you want to learn about and read the `README.md` file within. 




## Why C++?

C++ is not super hard to type (like assembly) and not super easy to learn (like python), so it serves as a decent middle ground for all levels imo.

There will be updates where I use other programming languages, but I will primarily stick with C++.


## How to Grow This Knowledge Base
When adding a new concept, keep this format:
1. **What it is**
2. **Why it matters**
3. **Example idea**
