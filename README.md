# Programming-KWTD

Programming Know What To Do: a simple, manual knowledge base of programming concepts and things you should know before building something.

## Knowledge Base

### Variables
- **What it is:** A named place to store data.
- **Why it matters:** Lets you reuse and update values in your program.
- **Example idea:** Store a user's score in a variable named `score`.

### Functions
- **What it is:** A reusable block of code that does one task.
- **Why it matters:** Reduces repetition and makes code easier to read.
- **Example idea:** A function `calculateTotal(price, tax)` returns a final amount.

### Conditionals
- **What it is:** Logic that runs different code based on conditions (`if`, `else`, `switch`).
- **Why it matters:** Allows programs to make decisions.
- **Example idea:** If a password is wrong, show an error; otherwise log in.

### Loops
- **What it is:** A way to repeat code (`for`, `while`, `for...of`).
- **Why it matters:** Helps process many items efficiently.
- **Example idea:** Loop through a list of tasks and print each one.

### Data Structures
- **What it is:** Ways to organize data (arrays, objects/maps, sets).
- **Why it matters:** Choosing the right structure improves clarity and performance.
- **Example idea:** Use an array for ordered items, use an object/map for key-value lookup.

### Scope
- **What it is:** Where a variable can be accessed (local vs global).
- **Why it matters:** Prevents naming conflicts and unintended side effects.
- **Example idea:** A variable inside a function should not be available outside it.
